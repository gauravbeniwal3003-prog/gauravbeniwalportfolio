IMAGE FOLDER INSTRUCTIONS
===========================

1. PROFILE PHOTO:
Place your photo here as:
   public/images/profile.webp
   (or .jpg / .png)
Recommended size: Square or Portrait (800x1000px or 1000x1000px), WebP format.
The website includes an automatic fallback to profile-placeholder.svg if your photo file is missing.

2. PROJECT PHOTOS:
Place your project screenshots/cover images in:
   public/images/projects/
Example files:
   project-1.webp
   project-2.webp
   project-3.webp
   project-4.webp

Then reference them in src/data/projects.ts!
WebP is recommended for ultra-fast loading.
